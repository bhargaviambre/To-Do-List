# To-Do-List
A simple and responsive To-Do List web application built using **HTML, CSS, JavaScript**.

The app allows users to add tasks, mark them as completed, delete tasks, and save tasks using browser localStorage.

##Features
-Add new tasks
-Add tasks using the Enter key
-Mark tasks as completed
-Delete tasks
-Tasks are saved using localStorage
-Tasks remain after refreshing the page
-Brown and beige themed UI
-Responsive design
-DOM manipulation using JavaScript

##Technologies Used
-HTML-Structure
-CSS-Styling and responsive design 
-JavaScript-Functionality and DOM manipulation
-LocalStorage-Data persistence

##How to run
-Download repository
-Open project folder
-Open index.html in browser
-start adding tasks!
